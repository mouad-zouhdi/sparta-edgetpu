# Requires Python 3.12. The 1.x line of onnx2tf routes conversion through the
# MLIR backend, which produces flatbuffers that make edgetpu_compiler segfault

# See synthetic/build_one.py for the full account.

# CUDA build: torch is pinned to the cu128 wheel because the cluster hosts
# Blackwell GPUs (sm_120), which earlier CUDA builds do not support.
# ---------------------------------------------------------------------------
